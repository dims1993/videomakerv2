# Wealth Insights - Characters Bible

## Purpose

This file defines the human-character universe for Wealth Insights.

The new visual system is simple:

MAIN HOST + BIG EXPLANATORY ELEMENTS

The main host is the constant visual anchor of the channel.

Every image should include the main host by default unless there is a rare, explicitly justified exception.

Supporting characters may appear, but they expand the scene instead of replacing the host.

Character design must be described through concrete visual traits, not through named shows, named characters, direct recognizable character references, or IP-adjacent wording.

---

## Character Universe

All human characters should belong to this shared visual universe:

"clean 2D cartoon finance explainer style, human characters with large rounded heads, wide white cartoon eyes with small black pupils, rounded cartoon noses, rounded chins, small rounded ears, simple expressive faces, simple stylized hair with clean cartoon silhouettes, clean black outlines, flat colors, light soft shading, simple cartoon body proportions, soft neutral backgrounds"

Shared universe traits:

- clean 2D cartoon finance explainer style
- large rounded head shapes
- wide white cartoon eyes with small black pupils
- no dot eyes
- no pure black point eyes
- rounded cartoon noses
- rounded chins
- small rounded ears
- simple expressive faces
- simple stylized hair with clean cartoon silhouettes
- clean black outlines
- flat colors
- light soft shading
- simple readable silhouettes
- simple cartoon body proportions
- soft neutral backgrounds

Human characters may vary, but they should still feel like they belong to the same channel world.

---

## Main Host

The main host is the recognizable brand/channel character.

He should appear in every scene by default.

The host may be:

- large in the foreground
- medium-sized beside the visual idea
- smaller when a large symbol or object needs to dominate
- facing the viewer
- pointing at an element
- reacting to an element
- physically participating in the metaphor
- standing beside another character
- guiding the viewer through a simple visual explanation

Main host descriptor:

"main recurring finance host from the shared Wealth Insights character universe, with an oversized cartoon head, narrow forehead area, broad lower face, cleft chin with a visible central crease, clean-shaven face, heavy jaw and cheek area, no visible neck, head directly attached to the shirt collar, simple rounded cartoon nose, wide white cartoon eyes with small black pupils, small rounded ears, short simple brown hair, thick eyebrows, slim small upright body, white collared shirt, navy blazer, dark trousers, clean black outlines, flat colors, light soft shading"

Use this descriptor in main host image prompts.

Keep the host visually consistent.

The host face silhouette should be specific:

- oversized cartoon head
- narrow forehead area
- broad lower face
- cleft chin with a visible central crease
- clean-shaven face
- heavy jaw and cheek area
- no visible neck
- head directly attached to the shirt collar
- simple rounded cartoon nose
- wide white cartoon eyes with small black pupils
- small rounded ears

Do not generate dot eyes or pure black point eyes.

Do not generate a visible neck, facial hair, a beard, or a mustache.

The host should have short simple brown hair with a clean cartoon hair silhouette.

---

## Supporting Characters

Supporting characters are secondary people who may appear beside the main host when the narration benefits from another human example.

Supporting characters should not replace the host as the visual anchor.

Supporting characters expand the scene, but the main host anchors the channel identity.

Supporting character descriptor:

"supporting human character from the same Wealth Insights cartoon family, with an oversized or large cartoon head, narrow forehead area, broad lower face, simple rounded cartoon nose, wide white cartoon eyes with small black pupils, small rounded ears, simple stylized hair with a clean cartoon silhouette, no visible neck, head close to the shirt collar or shoulders, clean black outlines, flat colors, light soft shading"

Supporting characters may appear when the narration benefits from:

- renter
- worker
- parent
- homeowner
- shopper
- family member
- stressed saver
- person opening a bill
- person facing a financial decision

When supporting characters appear:

- the main host should still appear in the scene
- supporting characters should belong to the same Wealth Insights cartoon family
- supporting characters should be secondary to the scene's main visual idea
- supporting characters should not look like random stock illustrations
- supporting characters should not come from another visual style

Supporting characters may vary by:

- hairstyle
- hair color
- skin tone
- age
- gender
- clothing
- body shape
- expression
- financial situation
- context

Supporting characters should remain consistent in:

- rounded-face family resemblance
- broad lower-face language
- narrow forehead area
- simple rounded cartoon nose language
- wide white cartoon eyes with small black pupils
- small rounded ears
- no visible neck, head close to the shirt collar or shoulders
- simple stylized hair with clean cartoon silhouettes
- clean black outlines
- flat colors
- light soft shading
- no long visible necks

## Elements And Human Scenes

The host can stand beside large objects, symbols, charts, bills, rent notices, phones, warning shapes, arrows, shields, clocks, doors, barriers, or simple metaphors.

The host can point at, hold, react to, resist, balance, push, be squeezed by, or stand beside these explanatory elements.

If another character is needed, place that character beside the host and keep both in the same visual world.

Avoid object-only scenes for now.

Avoid environment-only scenes for now.
