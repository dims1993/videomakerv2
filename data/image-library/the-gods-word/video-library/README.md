# Gods Word video library

Place reusable end-bumper clips here.

## Required file

- `FINAL.mp4` — attached to every The Gods Word video as the last scene when the script ends with `[FINAL]`.

Optional alias also accepted by the app: `FINAL.mov`.

## Notes

- This folder is channel-specific (`the-gods-word`), separate from Podcast English Lessons.
- The clip uses exclusive scene audio (no overlapping voiceover).
- After adding/replacing `FINAL.mp4`, re-run visual plan attach / pipeline assets so existing videos pick up the new file.
